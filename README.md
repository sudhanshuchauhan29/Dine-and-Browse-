# Dine And Browse

Dine And Browse is a web application designed to help users discover and explore local restaurants and bookstores in the Tirwa and Kannauj region. It provides a curated list of featured establishments, categorized browsing options, and search functionality to find the perfect spot to eat or read.

## Features

- **Featured Restaurants**: A showcased list of popular dining spots.
- **Featured Bookstores**: A showcased list of local bookstores and libraries.
- **Categorized Browsing**: Explore places by interest:
  - **Restaurants**: Visit, Adventure, Shopping.
  - **Bookstores**: Learning, Gaining, Developing.
- **Search Functionality**: Quickly find specific restaurants or bookstores.
- **Detailed Pages**: Each establishment has its own page with location details and maps.
- **Responsive Design**: Optimized for various screen sizes (Mobile, Tablet, Desktop).

## Project Structure

```text
Dine and Browse/
├── index.html        # Main landing page
├── Search.html       # Search page
├── variety.html      # Category-based browsing page
├── HTML/             # Detailed pages for establishments and contact info
├── CSS/              # Stylesheets for different components
├── js/               # JavaScript for data and application logic
└── assests/          # Project images (Note: folder name contains a typo)
```

## Technologies Used

- **HTML5**: For page structure and content.
- **CSS3**: For responsive styling and layout.
- **JavaScript (Vanilla)**: For dynamic content rendering and search logic.

## Getting Started

To run the project locally, simply open the `index.html` file in any modern web browser.

1. Clone or download the repository.
2. Navigate to the project root directory.
3. Open `index.html` using Chrome, Firefox, Safari, or any other web browser.
